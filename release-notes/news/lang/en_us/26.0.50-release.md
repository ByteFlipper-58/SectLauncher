## SectLauncher 26.0.50-release — Skins & Capes, refreshed settings, and a snappier UI

### 🎨 Skins & Capes — full management in the launcher
* A new **Skins & Capes** section is now available in the sidebar.
* You can browse your skin library, create new skins, copy, rename, edit, and delete saved ones.
* An interactive **3D preview** lets you rotate the model, zoom in, switch poses, toggle the outer layer, and enable character animation.
* Both **Classic** (4-pixel arms) and **Slim** (3-pixel arms) arm models are supported.
* All official Mojang default skins are included so you always have something to start from.
* Cape management is built in: select an owned cape, upload a local one, or hide your cape entirely.
* **Offline accounts** are fully supported — skins and capes are stored locally per account and automatically applied before launch on Forge, NeoForge, Fabric, and Quilt instances via CustomSkinLoader.
* Microsoft accounts continue to use the official Minecraft Services API as before.

### ⚙️ Refreshed settings layout
* The settings pages have been redesigned with a cleaner, more consistent look.
* Controls are grouped into dedicated cards and sections, making it easier to find what you need.
* A shared settings UI kit was introduced internally to keep all settings components visually consistent.

### ⚡ Smoother performance
* Search bars in Mods and Worlds are now **debounced** — the list updates after you stop typing instead of on every keystroke.
* Search bars stay **sticky** at the top while you scroll through results.
* Mod cards are now memoized to avoid unnecessary re-renders when nothing has changed.
* The Mod Detail view is **lazy-loaded**, which reduces the initial bundle size and speeds up startup.

### 📐 Better responsive layouts
* The Instances, Mods, and Worlds pages now adapt more cleanly to different window sizes.
* The installed mods grid uses a measured column layout that stays in sync with the actual available width.
* Page headers, toolbars, filter sidebars, and modal dialogs have been refined for consistency across all screen sizes.

### 🔧 Under the hood
* Cache configuration and helpers were centralized on the Rust side, reducing duplication across Modrinth and CurseForge downloaders.
* Error handling was streamlined with a shared extension, and audit logging now uses a unified wrapper.
* Microsoft device-code authentication now has a timeout with a clear message if the login window is left open too long.
